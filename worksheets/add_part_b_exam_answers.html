2.
כינוס חיוביים: 5⅓ + 4⅔ + 2¼ + 3¼ = 5⅓ + 4⅔ + 5½ 5⅓ + 4⅔ = 10  |  2¼ + 3¼ = 5½  →  10 + 5½ = 15½ כינוס שליליים: (−7½) + (−2½) + (−6¼) + (−3¾) (−7½) + (−2½) = −10  |  (−6¼) + (−3¾) = −10  →  −20 15½ + (−20) = −4½

4. שאלת חשיבה — טענת מיכל:
מיכל צודקת ✓
חוק החילוף בחיבור קובע שסדר החיבור אינו משנה את התוצאה — גם עם מספרים שליליים. לכן, כינוס כל החיוביים ביחד וכל השליליים ביחד מותר לחלוטין.
דוגמה: (−3) + 5 + (−1) + 4 = (5 + 4) + (−3 + −1) = 9 + (−4) = 5
