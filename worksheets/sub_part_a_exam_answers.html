תשובות — חיסור = חיבור הנגדי
כיתה ז׳  |  מורה בלבד
חן מרגלית למידה אקטיבית
חלק א׳ — הבנת הכלל
1. כתיבה מחדש כחיבור הנגדי:
א. 4 − (−7)
= 4 + 7
ב. −3 − 5
= −3 + (−5)
ג. −6 − (−2)
= −6 + 2
ד. 0 − (−9)
= 0 + 9
ה. a − (−b)
= a + b
2. פתרו:
א. 6 − (−5)
= 6 + 5 = 11
ב. −8 − 3
= −8 + (−3) = −11
ג. −1 − (−10)
= −1 + 10 = 9
ד. −3 − (−½)
= −3 + ½ = −2½
ה. 0 − 12
−12
3. קביעת סימן ללא חישוב:
א. 2.0145 − (−2.0345) = 2.0145 + 2.0345 — שני מחוברים חיוביים → חיובי
ב. −2.0145 − (−2.0345) = −2.0145 + 2.0345 = +0.02 → חיובי (2.0345 גדול יותר)
4. כשמחסרים מספר שלילי, התוצאה תמיד:
גדולה יותר מהמספר המקורי — כי חיסור שלילי = חיבור חיובי, ומוסיפים ערך חיובי.
5. כאשר b = −a (מספרים נגדיים): a − b = a − (−a) = a + a = 2a; בעוד b − a = −a − a = −2a.
לא נכון בדרך כלל. a − b = b − a רק כאשר 2a = −2a, כלומר a = 0.
