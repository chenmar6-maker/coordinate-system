מבדק שליטה — אורכים ושטחים
1. מרחק בין נקודות:
א. A(−3,4) ו-B(5,4): |5−(−3)| = 8 יחידות
ב. C(2,−3) ו-D(2,6): |6−(−3)| = 9 יחידות
ג. E(−4,−1) ו-F(3,−1): |3−(−4)| = 7 יחידות
2. מלבן A(−3,2), B(4,2), C(4,−1), D(−3,−1):
א. AB = |4−(−3)| = 7
ב. BC = |2−(−1)| = 3
ג. היקף = 2·(7+3) = 20 יחידות
ד. שטח = 7·3 = 21 יחידות רבועות
3. מלבן PQRS עם Q(2,−1), R(2,n), QR=4:
א. |n−(−1)| = 4 → n+1=4 → n = 3
ב. P(−3, −1)
ג. SR = |2−(−3)| = 5; היקף = 2·(5+4) = 18 יחידות
ד. שטח = 5·4 = 20 יחידות רבועות
4. A(a,b) כאשר a<0, b<0: B = (−a, −b) → −a>0, −b>0.
