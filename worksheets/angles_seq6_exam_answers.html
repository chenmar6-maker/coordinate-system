רצף 6 — זוויות קודקודיות
22. זוויות קודקודיות וצמודות
א. α=70°
β = 180°−70° = 110°
α' = 70° (קודקודית) = 70°
β' = 110° (קודקודית) = 110°
ב. α=115°
β = 180°−115° = 65°
α' = 115° (קודקודית) = 115°
β' = 65° (קודקודית) = 65°
23. ① = 40°. שאר הזוויות:
② = 180°−40° = 140° (צמודה ל-①)
③ = 40° (קודקודית ל-①) = 40°
④ = 140° (קודקודית ל-②) = 140°
24. זוויות שכנות שוות בחיתוך שני קווים
אם הזוויות השכנות שוות: x + x = 180° → x = 90°.
תשובה: 90° לכולן
25. נכון / לא נכון
א. זוויות קודקודיות תמיד שוות: נכון
ב. 4 זוויות שכולן שוות תמיד: לא נכון — רק אם הקווים ניצבים
ג. אחת 90° → כל הארבע 90°: נכון — כי צמודות ל-90° = 90°
ד. סכום כל הארבע = 360° תמיד: נכון
26. ממעוף הציפור — מדוע מספיקה זווית אחת?
מזווית אחת (למשל α) אפשר לחשב את שלוש האחרות:
— הצמודות לה = 180°−α (עקרון הזוויות הצמודות)
— הקודקודית לה = α (עקרון הזוויות הקודקודיות)
— הרביעית = צמודה לקודקודית = 180°−α
לכן שני העקרונות מספיקים לחישוב הכול.
