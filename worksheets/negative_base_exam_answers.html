2. נכון / לא נכון:
• (−3)² = −9 — לא נכון ((−3)²=9, כי מינוס·מינוס=פלוס)
• −5² = −25 — נכון (הבסיס הוא 5, המינוס בחוץ)
• (−2)³ = 8 — לא נכון ((−2)³=−8, מעריך אי-זוגי→שלילי)
• (−1)¹⁰ = 1 — נכון (מעריך זוגי→חיובי)
• (−4)² = 4² = 16 — נכון
• −2² = (−2)² — לא נכון (−2²=−4 אך (−2)²=4)
3. טבלה — מי הבסיס:
• (−3)² : בסיס=−3, תוצאה=9, חיובי
• −3² : בסיס=3, תוצאה=−9, שלילי
• (−2)⁴ : בסיס=−2, תוצאה=16, חיובי
• (−2)⁵ : בסיס=−2, תוצאה=−32, שלילי
4. השלימו:
• (−3)² = 3²
• (−2)³ < 2³  (−8 < 8)
• −4² < (−4)²  (−16 < 16)
• (−1)⁶ > (−1)⁷  (1 > −1)
• (−5)² > −5²  (25 > −25)
• −3² = −9
5. סדר פעולות:
א. −2² + (−2)² = −4 + 4 = 0
ב. (−3)² − 3² = 9 − 9 = 0
ג. 2·(−3)² = 2·9 = 18
ד. (−2)⁴ − (−2)³ = 16 − (−8) = 24
6. הסבר:
ב-(−a)ⁿ: הבסיס הוא −a (שלילי). המינוס בתוך הסוגריים — הוא חלק מהבסיס.
ב-−aⁿ: הבסיס הוא a (חיובי). המינוס נמצא מחוץ לחזקה — מוחסר לאחר החישוב.
לכן: (−3)² = 9, אבל −3² = −9.
