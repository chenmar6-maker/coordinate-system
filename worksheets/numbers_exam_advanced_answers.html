2. מציאת הריבוע: (□ − 6) ÷ (−2) + 3·(−4) = −8
(□ − 6) ÷ (−2) + (−12) = −8

3. |a|=7, |b|=3, a+b<0, a·b<0 — מציאת a−b
נימוק:
• a·b < 0 → אחד חיובי ואחד שלילי
• a+b < 0 → המספר השלילי גדול יותר בערכו המוחלט
• |a|=7 > |b|=3, לכן a שלילי (a = −7) וb חיובי (b = 3)
בדיקה: a+b = −7+3 = −4 < 0 ✓  |  a·b = −7·3 = −21 < 0 ✓
a − b = −7 − 3 = −10
4. a מספר שלילי — סדר: a, a/2, 2a, −a מקטן לגדול
דוגמה עם a = −4:
2a = −8  |  a = −4  |  a/2 = −2  |  −a = 4
סדר מקטן לגדול: 2a < a < a/2 < −a
כלל: כפל מספר שלילי ב-2 מגדיל את הערך המוחלט → מקטין עוד יותר. חלוקה ב-2 מקרבת לאפס.
5. מפלס בריכה — ירידה 12 ס"מ/שעה; 14:00 מראה −30 ס"מ
מ-9:00 ל-14:00 = 5 שעות
הבריכה ירדה 5×12 = 60 ס"מ בין 9:00 ל-14:00
לכן ב-9:00 המד הראה: −30 + 60 = +30 ס"מ

10. O(0,0), A(0,6), B(8,0) — מציאת G על ציר x כך ש-שטח AOG = שטח AOB
שטח AOB:
בסיס OA = 6 (ציר y), גובה = מרחק B מציר y = 8
שטח = ½ × 6 × 8 = 24
שטח AOG (G על ציר x, G=(g,0)):
גובה = מרחק A מציר x = 6, בסיס OG = |g|
½ × |g| × 6 = 24 → |g| = 8
G = (8, 0) = B (אסור)   →   G = (−8, 0)

12. c<0<b<a, |a|<|c|<|b| — איזה ביטוי מקבל את הערך הגדול ביותר?
דוגמה: a=1, c=−2, b=3 (מקיים: c<0<b<a? לא... נסה: a=2, c=−3, b=4)
בדיקה עם a=2, b=4, c=−3:
א. b−a = 4−2 = 2  |  ב. a+c = 2+(−3) = −1
ג. a−b = 2−4 = −2  |  ד. b+c = 4+(−3) = 1
א. b − a ✓ ב. a + c ג. a − b ד. b + c
תשובה נכונה: א
