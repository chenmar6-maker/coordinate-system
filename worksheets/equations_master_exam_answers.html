חלק א׳ — זיהוי פתרון המשוואה
1. פתרונות נכונים:
א. 5x − 3 = 7
5·2−3 = 7 ✓   →   x = 2
ב. −x/3 + 1 = 3
6/3+1 = 3 ✓   →   x = −6
ג. 4x + 3 = −5
4·(−2)+3 = −5 ✓   →   x = −2
ד. x + 5 = 3x − 1
3+5=8, 9−1=8 ✓   →   x = 3
ה. 2(x − 4) = 6
2·(7−4)=6 ✓   →   x = 7
2. המשוואות שפתרונן x = 5 (מסומנות בירוק):
3x − 5 = 10 ✓
x + 3 = 7 ✗
−x + 7 = 2 ✓
2(x + 1) = 12 ✓
x5 = 1 ✓
x − 8 = −4 ✗
