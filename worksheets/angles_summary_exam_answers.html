חן מרגלית למידה אקטיבית
תרגיל 1
חישוב הזווית α
(ב) שלוש זוויות יוצרות יחד זווית שטוחה

זווית שטוחה = 180°, לכן: α + 2α + 60° = 180°

3α = 120°  ⟹  α = 40°

(ג) BC הוארכה עד D — זווית חיצונית

זווית חיצונית של משולש = סכום שתי הזוויות הפנימיות הלא-צמודות:

130° = 55° + α  ⟹  α = 75°

תרגיל 2
שני ישרים נחתכים
(א) זוויות צמודות וקודקודיות

צמודות (לדוגמה): α ו-β (או: α ו-δ, β ו-γ, γ ו-δ — כל אחד מהזוגות הצמודים תקין)

קודקודיות (לדוגמה): α ו-γ (או: β ו-δ)

(ג) α גדולה פי 3 מ-β

α ו-β צמודות: α + β = 180°

3β + β = 180°  ⟹  β = 45°, α = 135°

קודקודיות: α = γ = 135°,  β = δ = 45°

(ד) γ ישרה — בחרו את הטענה הנכונה

② כל ארבע הזוויות שוות זו לזו.

אם γ = 90°, אז α = γ = 90° (קודקודיות), ו-β = δ = 90° (צמודות ל-α). כל הזוויות 90°.

תרגיל 3
המספריים
(א) שני זוגות זוויות שוות

∡OPQ = ∡OQP = 55° — משולש OPQ שווה-שוקיים (OP = OQ), לכן זוויות הבסיס שוות.

∡ORS = ∡OSR — משולש ORS שווה-שוקיים (OR = OS).

(בנוסף: ∡POQ = ∡ROS — זוויות קודקודיות.)

(ב) חישוב ∡POQ

סכום זוויות במשולש OPQ: ∡POQ = 180° − 55° − 55°  ⟹  ∡POQ = 70°

(ג) חישוב ∡ROS ו-∡ORS

∡ROS = 70° — קודקודית ל-∡POQ.

∡ORS = (180° − 70°) ÷ 2 = 55°  ⟹  ∡ORS = 55°

(ד) האם PQ ∥ RS?

כן. ∡OPQ = ∡ORS = 55°. אלה זוויות מתחלפות (P,O,R על ישר אחד), ולכן PQ ∥ RS.

תרגיל 4
הסולם והמדף
(א) חישוב ∡FWC

במשולש WFC: ∡WCF = 90° (קיר מאונך לרצפה), ∡WFC = 68°

∡FWC = 180° − 90° − 68°  ⟹  ∡FWC = 22°

(ב) חישוב ∡WKM ו-∡MKF

MN ∥ לרצפה FC, והסולם הוא החותך. ∡WKN = ∡WFC = 68° (זוויות מתאימות).

∡WKM = 180° − 68° = 112° (זוויות משלימות על ישר MN)

∡MKF = 68° (קודקודית ל-∡WKN, או: זוויות מתחלפות עם ∡KFC)

(ג) הטענה הנכונה

① ∡MKF = ∡KFC כי הן זוויות מתחלפות.

MN ∥ FC, חותך WF: ∡MKF ו-∡KFC הן זוויות מתחלפות ולכן שוות (שתיהן 68°).

תרגיל 5
מרובע ומשולש שווה-צלעות
(א) חישוב ∡CDE

במשולש DEC: ∡C = 90°, ∡DEC = 40°

∡CDE = 180° − 90° − 40°  ⟹  ∡CDE = 50°

(ב) חישוב ∡AED

ABE שווה-צלעות: ∡BEA = 60°. הנקודות B,E,C על ישר אחד:

∡AED = 180° − ∡BEA − ∡DEC = 180° − 60° − 40°  ⟹  ∡AED = 80°

(ג) חישוב ∡EAD ו-∡EDA

משולש AED שווה-שוקיים (AE = ED), לכן זוויות הבסיס שוות:

∡EAD = ∡EDA = (180° − 80°) ÷ 2  ⟹  ∡EAD = ∡EDA = 50°

(ד) זוויות המרובע ABCD

∡A = 60° + 50° = 110°   (∡BAE ממשולש שווה-צלעות + ∡EAD)

∡B = 60°   (זווית במשולש שווה-צלעות ABE, ו-E על BC)

∡C = 90°   (נתון)

∡D = 50° + 50° = 100°   (∡CDE + ∡EDA)

סכום: 110° + 60° + 90° + 100° = 360° ✓

אתגר — תרגיל 6
משולש שווה-שוקיים עם חוצה-זווית
(א) חישוב ∡ABC ו-∡ACB

ABC שווה-שוקיים (AB = AC): ∡ABC = ∡ACB = (180° − 36°) ÷ 2

∡ABC = ∡ACB = 72°

(ב) חישוב ∡DBC ו-∡BDC

BD חוצה את ∡ABC: ∡DBC = 72° ÷ 2 = 36°

במשולש BDC: ∡BDC = 180° − 36° − 72°  ⟹  ∡BDC = 72°

(ג) עוד שני משולשים שווי-שוקיים

משולש ABD: ∡BAD = 36°, ∡ABD = 36° ⟹ שווה-שוקיים (BD = AD).

משולש BDC: ∡BDC = ∡BCD = 72° ⟹ שווה-שוקיים (BD = BC).

(ד) מה אפשר לומר על AD, BD, BC?

ממשולש ABD שווה-שוקיים: AD = BD.

ממשולש BDC שווה-שוקיים: BD = BC.

לכן: AD = BD = BC
