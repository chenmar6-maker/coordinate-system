18. שתי זוויות צמודות שוות
x + x = 180° → 2x = 180° → x = 90°
19. האחת גדולה פי 4 מהשנייה
x + 4x = 180° → 5x = 180° → x = 36°
קטנה = 36°  |  גדולה = 144°
20. גדולה = 3 × קטנה
x + 3x = 180° → 4x = 180° → x = 45°
קטנה = 45°  |  גדולה = 135°

א. סכומן תמיד 180°: נכון

ג. יכולות להיות שתיהן קהות: לא נכון — שתי קהות יחד > 180°
